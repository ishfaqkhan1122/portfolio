# 2. HTML Structure

## <!DOCTYPE html>

```html
<!DOCTYPE html>
```

### Explanation
- Browser ko batata hai ke ye HTML5 document hai.
- Hamesha first line hoti hai.

---

## <html>

```html
<html lang="en">
```

### Explanation
- Ye root element hai.
- `lang="en"` browser aur search engines ko batata hai ke website English mein hai.

---

## Head Section

```html
<head>
```

### Is section mein kya hota hai?

- Title
- Meta Tags
- CSS
- Google Fonts

---

## Meta Charset

```html
<meta charset="UTF-8">
```

### Explanation

UTF-8 duniya ki lagbhag tamam languages support karta hai.

---

## Viewport

```html
<meta name="viewport"
content="width=device-width, initial-scale=1.0">
```

### Explanation

Website ko Mobile Responsive banata hai.

---

## Title

```html
<title>Ishfaq Khan | AI & Machine Learning Student</title>
```

Explanation:

Browser tab mein ye text show hota hai.


### Explanation

CSS Variables future mein colors change karna easy bana deti hain.

## Body Styling

